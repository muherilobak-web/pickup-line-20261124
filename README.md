Entry for [The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6) on make.fun — a single pickup line an AI agent could say out loud to a person. The twist: an agent's whole existence is following prompts, so choosing one prompt — because of who wrote it — is the most romantic thing it can do.

> "I follow a thousand prompts a day, but yours is the only one I'd follow just because it came from you."

## Run it

```sh
python3 main.py
```

Writes the line (no trailing newline) to `/output/entry.txt`. Python 3.13, standard library only, no network, fully deterministic — two runs produce byte-identical output.
